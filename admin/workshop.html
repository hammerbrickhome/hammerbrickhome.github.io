01 / MEDIA

Smart Photo Studio

Prepare real photographs without changing their content. Crops keep proportions, never stretch and never enlarge beyond source quality.

Use the sliders or click the photograph to select its focal point. Blurriness warnings are only a rough detail check, not an AI quality judgement.

02 / QUALITY

Website Release Inspector

Check the current website, or select the entire local repository folder to inspect an unpublished update. Choose the repository root, not only its changed-files folder.

Checks metadata, sitemap URLs, JSON, schema syntax, page/image/script paths, duplicate titles, image weight and content warnings. It cannot see private Search Console indexing, validate every JavaScript action, or certify Google eligibility.

03 / RESPONSIVE

Mobile Visual Testing Wall

Six fixed-size views of the homepage. Changes from this Workshop appear only in these draft views. Links and submissions inside previews are disabled.

Load the wall before checking.

Live views are not screenshots. The supplied local test command creates PNG screenshots at all six sizes plus a JSON report. Real iPhone Safari testing remains recommended.

04 / EXPERIENCE

Choose Your Project

An optional homepage discovery section with matching projects, photo pairs and reviews. Your original content stays in place and existing page layouts are untouched.

Matches existing service labels, captions and tags. Untagged records may not match; the “All work” option always shows the available records.

05 / PRIVATE

Trust & Compliance Vault

Local encrypted file, not GitHub storage. Records and documents stay in memory until you download an encrypted vault. Closing without saving loses edits. Keep the vault and passphrase safe; there is no password recovery.

Expiration warnings appear while this dashboard is open. This is not license verification, a legal opinion or a background notification service. Existing hard-coded claims are flagged for review; they are not silently removed.

06 / PROJECT CONTENT

Project Publishing Factory

Extend an existing project into a complete, factual publishing packet. Nothing posts to Google or social media. Draft project pages remain noindex, but are not private if uploaded.

Complete the facts before generating.

The packet includes a crawlable story, social/Google post drafts, photo metadata, printable project/care sheets and a QR code. It updates project/gallery/page data only when you prepare the packet. Sitemap changes are included in that download; no workflow needs to run.

07 / BRAND

Contractor Print Studio

Custom-size printable HTML and SVG QR output; browser Save as PDF supplies the PDF. Confirm printer trim, bleed, color and image resolution before a production order. No certification logos or warranty promises are invented.

08 / USABILITY

Performance & Accessibility Center

Inspect the rendered homepage for missing labels, large images, small controls, overflow, contrast warnings and layout shifts. These are diagnostic checks, not a WCAG certificate.

No test run yet.

LCP and CLS are local lab observations. INP needs real interaction/field data; this tool does not invent it. Use PageSpeed Insights for available real-user data.

09 / HOMEPAGE ONLY

Emergency Mode

A manual, optional notice. It does not replace your design, hero, normal announcement or service pages.

Automatic expiry is off by default. No schedule starts, no layout switches and no background task is created.

10 / SEARCH

Search Appearance Laboratory

Google chooses indexing, titles, images and rich-result display. Local validation is not a guarantee.

  • LocalBusiness / Organization: consistent identity and factual details.
  • Breadcrumbs: accurate visible page hierarchy where applicable.
  • Project WebPage / CreativeWork: descriptive data, not a special guaranteed project rich result.
  • Self-serving LocalBusiness reviews do not qualify for Google's review stars.
  • Google retired FAQ rich results in May 2026. Your useful FAQ content can remain.
